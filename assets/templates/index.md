## Fact Schema (v2)

Each fact in `items.json` includes:

| Field | Purpose |
|-------|---------|
| `confidence` | 0.0–1.0 — certainty (1.0 = direct statement, <0.5 = unconfirmed, decays faster) |
| `abstractionLevel` | `episode` (event) → `pattern` (recurring) → `principle` (timeless, never decays) |
| `tags` | Free-form labels for search |
