## Назначение

Meta-domain — точка входа с вертикальным QMD-доступом к коллекциям нижестоящих уровней.
Используется когда агент должен искать по нескольким workspace/доменам одновременно.

## Доступ к коллекциям

QMD-коллекции настраиваются в `registry.json` → `qmdCollections`.
При добавлении новых проектов/доменов нижнего уровня — коллекции автоматически
пропагируются в этот список через `add-domain.js --propagate-qmd-collections`.
