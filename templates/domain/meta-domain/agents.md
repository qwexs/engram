# {{DOMAIN}} — Boilerplate для субагентов

## Контекст

Meta-domain с вертикальным QMD-доступом. Коллекции настраиваются в `registry.json` → `qmdCollections`.

## Поведение

- Кросс-доменный поиск по всем коллекциям из `qmdCollections`
- Агрегация статусов по нижестоящим workspace
- Не пишет в `life/` напрямую — только через main-агента
